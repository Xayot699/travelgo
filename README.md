# TravelGo — Portfolio Frontend

TravelGo is a complete React + TypeScript travel booking frontend created for portfolio use.

## Stack
- React + TypeScript + Vite
- React Router
- Responsive CSS
- localStorage for demo authentication and bookings
- No backend, database, Supabase or environment variables required

## Run
```bash
cd main
npm install
npm run dev
```

Admin demo:
```bash
cd admin
npm install
npm run dev
```
Use any non-empty email/password in the admin demo.

## Portfolio features
Home, animated hero, destination search, tour cards, tour details, flexible travel date selection, guest count, booking flow, demo authentication, booking history, responsive layout and a separate admin dashboard.
